## 從 0 開始架設

### 1. 註冊 GitHub、建 repo
1. 到 github.com → **Sign up**，用 email 註冊（免費）。
2. 右上角 **+ → New repository**，名稱填 `2026-12-osaka`，選 **Public**，勾 **Add a README file** → **Create repository**。
3. **Add file → Upload files**，把 `index.html` 和這份 `README.md` 拖進去 → **Commit changes**。
4. **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 `main`、`/ (root)` → **Save**。
5. 等 1–2 分鐘，網址是 `https://<你的帳號>.github.io/2026-12-osaka/`。

### 2. 接 Google 試算表（讓大家一起改行程、記帳）
沒接之前網站是「示範模式」，改的東西只存在自己手機。

1. 新開一份 Google 試算表，取名「大阪聖誕」。
2. **擴充功能 → Apps Script**，刪掉預設內容，貼上 `Code.gs` 全部內容 → 儲存。
3. 上方函式選 **setup** → **執行** → 授權。出現「Google 尚未驗證這個應用程式」時點 **進階 → 前往（不安全）→ 允許**。
4. **部署 → 新增部署作業** → 齒輪選 **網頁應用程式**；執行身分 **我**、誰可以存取 **所有人** → 部署。
5. 複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`），交給 Claude 重新產生 `index.html`，再上傳一次。

第一次連上時，網站會自動把內建的行程和兩筆帳寫進試算表。

## 日常更新
- **行程、帳目**：直接在網頁上改，或改試算表，不用重新上傳。
- **版面、功能**：請 Claude 改好、用同一組密碼和 salt 重新加密，再上傳 `index.html` 覆蓋。檔名一定要是 `index.html`。
- **改了 Apps Script**：**部署 → 管理部署作業 → 鉛筆 → 版本：新版本 → 部署**。不要按「新增部署作業」，網址會變。

## 加密
```bash
npx staticrypt@3.5.4 index.html -p "<密碼>" --short --remember 30 --salt "<固定 salt>" -d out
```
salt 每次都要一樣，大家勾過的「記住我」才不會失效。

## 不要放進 repo
未加密的網頁原始檔、密碼、Apps Script 網址、試算表連結、訂位代號、機票號碼、護照資料。
